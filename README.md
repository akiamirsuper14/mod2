# Level 94 — Motion (прототип мода)

Тестовый мод для **Minecraft Java 1.20.1 + Forge 47.3.0** (Java 17).

## Что уже есть
- отдельное измерение `backrooms94:level_94` с обычной бесконечной noise-генерацией холмистой местности;
- постоянный дневной свет, без дождя и без спавна мобов;
- редкие маленькие домики из блоков Minecraft и каменные фонтаны как первые процедурные ориентиры;
- команды для операторов: `/level94 enter` и `/level94 exit`.

Генерация сейчас намеренно прототипная: базовые ландшафты и блоковые макеты, без собственных текстур, машин, замка, сущностей или сюжетных механик.

## Сборка и запуск

### Локально
1. Установи JDK 17 и Gradle 8.x.
2. В каталоге проекта выполни `gradle build`.
3. Готовый jar будет в `build/libs/`.

### Через GitHub Actions
В проект уже добавлен workflow `.github/workflows/build.yml`. Загрузи содержимое папки `level94-mod` в GitHub-репозиторий и отправь его в ветку `main` или `master` (либо запусти workflow вручную на вкладке **Actions**). После успешной сборки скачай артефакт `backrooms94-forge-1.20.1` со страницы запуска workflow.

Затем установи Forge 1.20.1, положи jar в `mods/`, запусти мир и введи `/level94 enter`.

Команды требуют права оператора (уровень 2). Для уже созданного мира может потребоваться полный перезапуск сервера после установки мода, чтобы datapack измерения был прочитан.
